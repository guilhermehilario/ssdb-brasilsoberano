Pente Fino

OSINT

Plataforma para investigação de corrupção no Brasil

O Pente Fino é uma plataforma OSINT (Open Source Intelligence) para investigação de corrupção no Brasil. Dividido em frontend e backend, oferece ferramentas para mapear conexões entre políticos, empresas e contratos suspeitos.

Arquitetura do Projeto

Frontend - pente-fino/

React 19 + TypeScript + Vite + Tailwind CSS

  • Busca unificada de políticos e empresas
  • Dashboard detalhado com alertas
  • Mapa de conexões interativo (ForceGraph2D)
  • Dashboard de cruzamento de dados
  • Busca inteligente com coleta em segundo plano
Backend - api-pente-fino/

Node.js + Express 5 + Prisma + PostgreSQL

  • Integração com APIs públicas brasileiras
  • Sistema de cache e fallback automático
  • Busca inteligente com desambiguação
  • Progresso em tempo real via SSE
  • Histórico de coletas e cancelamento

Fontes de Dados Integradas

Brasil API CNPJA Câmara dos Deputados Senado Federal TSE Receita Federal IBGE BCB Portal da Transparência Diário Oficial da União

Funcionalidades Principais

🔍 Busca Inteligente com Coleta em Tempo Real
🕸️ Grafo Interativo de Conexões
⚠️ Sistema de Alertas e Suspeitas
📊 Dashboard de Cruzamento de Dados
👥 Desambiguação de Homônimos
📈 Progresso Detalhado por Fonte

Objetivo: Facilitar a investigação cidadã e o jornalismo investigativo, tornando mais acessível o cruzamento de dados públicos para combater a corrupção.
